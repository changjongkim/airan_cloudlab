# Experiment tables

- `ISCA_EXPERIMENT_MATRIX_V2.csv`: 최신 계획 matrix
- `ISCA_EXECUTION_LEDGER_20260813.csv`: 계획 대비 실행 상태
- `ISCA_EXPERIMENT_MATRIX_20260813.csv`, `ISCA_TODAY_MATRIX_20260813.csv`: 날짜별 campaign 기록
- `DART_RX_SCHEME_ABLATION_V0.csv`: 초기 mechanism ablation 설계
- `all_results*.csv`: 초기 MIG 실험 요약

실제 최신 측정값은 [`../../data/README.md`](../../data/README.md)에 연결된 campaign별 분석 CSV를 우선한다.
