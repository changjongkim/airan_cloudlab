## Cross-figure paper story

```
Fig 01-06: Tier1 establishes baselines + initial observation
   → Some workloads cause large inflation (NeuralRx +3.7×, others +2×)
Fig 07-12: Extended multi-AI matrix M5-M12
   → Mixed: some +3.8%, some -8%
Fig 13-18: AI per-op shows L1 has small effect on most AIs (<+15%)
Fig 19-22: NCU shows DRAM is at most 12% peak — NOT saturated
Fig 23-31: Deep-dive (n=3) suggested various effects
Fig 32 ⭐⭐⭐: Dv2 (n=10) refutes earlier "effects" as noise
Fig 33: Long-tail analysis confirms tail behavior is universal
Fig 34: 5/31 F partial → 6/1 expansion (40 conds, all baseline-equivalent)
Fig 35-36: Sustained + partition sweep
```

**Final story**: small N earlier showed false-positive effects. Properly statistical n=10 / n=5 measurements show **cross-partition isolation works**. The real disturbance is **in-partition coloc** (analyzed in 20260601 G stage).
