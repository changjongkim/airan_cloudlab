## Paper Punchline

> "MIG mode itself imposes negligible overhead (7g MIG ≈ no-MIG), but AI-RAN co-location requires partition fragmentation, which costs 34-238% L1 latency depending on partition choice. AI leakage exists but is small for properly-sized partitions; partition cap dominates. The best feasible AI-RAN configuration (M4: 4g L1 + 3 light AI on 1g) still imposes +52% latency penalty. URLLC sub-millisecond p99 is infeasible in all measured MIG configurations."
